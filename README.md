# Python Programming Assessment: Numbers & Basic Logic

This repository contains my solution for the Python Programming Assessment.

## Functions

### 1. even_or_odd

The `even_or_odd` function takes an integer and checks whether it is even or odd.

I used the modulo operator (`%`) to check the remainder when the number is divided by 2.

- If the remainder is 0, the function returns `"Even"`.
- Otherwise, the function returns `"Odd"`.

### 2. add_all

The `add_all` function takes a list of numbers and returns their total.

I started with a total of 0 and used a `for` loop to go through each number in the list and add it to the total.

For an empty list, the function returns 0.

## Testing

I tested the functions with different inputs, including:

- Even number
- Odd number
- A list containing multiple numbers
- An empty list

The test cases produced the expected results.
